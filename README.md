# ML & Financial Research

Exploring the intersection of **Mathematics, Finance, and Machine Learning.**

This repository is my learning workspace — a place to experiment, implement concepts, work through mathematical ideas, and gradually build a deeper understanding of quantitative finance and machine learning.

I'm particularly interested in understanding the mathematics behind financial models rather than treating them as black boxes.

## Areas of Interest

- **Mathematics:** Linear Algebra, Calculus, Probability, Statistics, Optimization.
- **Finance:** Financial Markets, Quantitative Finance, Portfolio Theory, Risk Management.
- **Machine Learning:** Statistical Learning, Regression, Optimization, Feature Engineering, Model Evaluation.
